**[📦 Análise de E-commerce Brasileiro — Olist](https://github.com/BrendonSantos7/analise-ecommerce-olist)**

*Meu projeto mais completo até agora: pela primeira vez trabalhei com Python e dados reais de uma empresa brasileira.*

Neste projeto construí um pipeline de dados completo usando o dataset real da Olist — maior marketplace do Brasil — com ~100 mil pedidos entre 2016 e 2018. Do dado bruto ao dashboard executivo, passando por ETL, modelagem dimensional e SQL avançado.

<br>

- **🔹 O Desafio:** Unificar 9 tabelas brutas em um modelo analítico estruturado capaz de responder perguntas reais de negócio sobre vendas, logística e satisfação de clientes.
- **💡 A Solução:** ETL em Python (pandas + SQLAlchemy), modelagem dimensional no SQL Server com Esquema Estrela (5 tabelas, 248k linhas), queries avançadas em T-SQL com CTEs e Window Functions, e dashboard executivo no Power BI com DAX, tooltips interativos e navegação entre páginas.
- **🚀 O Impacto:** Identificou que estados do Nordeste pagam frete 2-3x maior que SP com prazo 2,5x mais longo — correlação direta com menor satisfação dos clientes. A Black Friday de 2017 gerou +52% de crescimento, confirmando padrões de sazonalidade para o planejamento comercial.

**[👥 People Analytics — Diagnóstico Estratégico de Turnover e Retenção](https://github.com/BrendonSantos7/projeto-rh-analytics)**

*Como o RH pode parar de apenas relatar demissões e começar a prever e evitar perdas financeiras?*

Neste projeto desenvolvi uma solução completa para identificar as causas raízes da evasão de talentos de uma empresa.

<br>

- **🔹 O Desafio:** Consolidar 7 bases de dados distintas de RH para criar uma visão unificada e estratégica do capital humano.
- **💡 A Solução:** Arquitetura de dados em Star Schema, inteligência de tempo em DAX para prever picos de saída e prototipação de UI/UX no Figma para garantir navegação intuitiva.
- **🚀 O Impacto:** O painel mapeou um impacto financeiro crítico de **R$ 3,90 milhões** em saídas voluntárias, permitindo aos gestores ações corretivas baseadas em dados, não em intuição.

**[💰 Solução End-to-End de Analytics — Finanças Corporativas/Pessoais](https://github.com/BrendonSantos7/Controle-Financeiro)**

*Um projeto que comprova domínio de ponta a ponta: desde a modelagem física em banco relacional até a entrega de valor visual.*

<br>

- **🔹 O Desafio:** Eliminar a dependência de planilhas manuais isoladas e criar um ecossistema de dados estruturado, seguro e escalável para análises financeiras.
- **💡 A Solução:** Data Warehouse local no SQL Server com regras de negócio direto no banco, modelagem dimensional e conexão direta com o Power BI para visualização de KPIs.
- **🚀 O Impacto:** Dashboard com clareza instantânea sobre saúde do caixa, cruzando receitas, despesas e saldo com análises de tendências — provando capacidade de integrar Back-end (banco de dados) e Front-end (BI).
