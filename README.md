**[👥 People Analytics — Diagnóstico Estratégico de Turnover e Retenção](https://github.com/BrendonSantos7/projeto-rh-analytics)**  
*Como o RH pode parar de apenas relatar demissões e começar a prever e evitar perdas financeiras?*  
Neste projeto, desenvolvi uma solução completa para identificar as causas raízes da evasão de talentos de uma empresa.
- **🔹 O Desafio:** Consolidar 7 bases de dados distintas e caóticas de RH para criar uma visão unificada e estratégica do capital humano.
- **💡 A Solução:** Arquitetura de dados em *Star Schema*, uso massivo de inteligência de tempo em DAX (para prever picos de saída) e prototipação de UI/UX aplicada no Figma para garantir uma navegação intuitiva.
- **🚀 O Impacto:** O painel traduziu dados demográficos em dinheiro, mapeando um impacto financeiro crítico de **R$ 3,90 milhões** em saídas voluntárias, permitindo aos gestores ações corretivas baseadas em dados, não em intuição.

**[💰 Solução End-to-End de Analytics — Finanças Corporativas/Pessoais](https://github.com/BrendonSantos7/Controle-Financeiro)**  
*Um projeto que comprova domínio de ponta a ponta: desde a modelagem física em banco de dados relacional até a entrega de valor visual.*  
- **🔹 O Desafio:** Eliminar a dependência de planilhas manuais isoladas e criar um ecossistema de dados estruturado, seguro e escalável para análises financeiras.
- **💡 A Solução:** Criação de um Data Warehouse local utilizando **SQL Server**, aplicando regras de negócio direto no banco, modelagem dimensional e, por fim, conexão direta e segura com o Power BI para a camada de visualização de KPIs.
- **🚀 O Impacto:** O dashboard oferece clareza instantânea sobre a saúde do caixa, cruzando receitas, despesas e saldo com análises de tendências temporais, provando capacidade de arquitetar soluções robustas que integram Back-end (Banco de dados) e Front-end (BI).
